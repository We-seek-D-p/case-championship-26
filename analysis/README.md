# Будущие Markdown-выводы

После загрузки настоящих первичных файлов Codex должен создать здесь согласованные аналитические материалы.

| Планируемый документ | Содержание |
|---|---|
| `01-coverage.md` | Что скачано и извлечено, какие пробелы остались |
| `02-market.md` | Объём рынка, авиакомпании, города и аэропорты |
| `03-network.md` | Действующая маршрутная сеть, частоты и конкуренты |
| `04-strategies.md` | Сравнение нового хаба и прямых рейсов на общих входах |

Эти документы **ещё не созданы**. Каждое фактическое число в будущем тексте должно ссылаться на `source_id`, период и первичный файл.
