Полные контакты пресс-службы из S59/S60 и агентств из S61 не экспортировались. Метаданные источников сохраняют публичные URL, в том числе URL новости о назначении руководителя; это не реквизиты доступа. Автоматический поиск шаблонов не гарантирует отсутствия всех возможных видов чувствительной информации. Результаты дополнительно просмотрены как предметные данные организаций; действующие на сегодня тарифы и законы не проверялись, архивные условия не выдаются за текущие.

Воспроизведение: `python scripts/process_airlines.py`, затем `python scripts/check_airlines.py`. Используется стандартная библиотека Python и системный `pdftotext`; дополнительная установка зависимостей не выполнялась. Нормализация определена проверенными спецификациями извлечения, а не универсальным парсером любых новостей.

Дополнительная разовая проверка с уже установленным BeautifulSoup подтвердила совпадение нормализованного текста выбранных контейнеров всех 15 HTML с независимым разбором. Для штатной сборки и проверки BeautifulSoup не нужен.

Коммит не создан: пользовательские инструкции запрещают агенту изменять индекс и создавать коммиты. Уже staged файлы других задач, включая сырые данные аэропортов, не изменялись. Для ручного коммита требуется ограничить пути результатами airlines.
