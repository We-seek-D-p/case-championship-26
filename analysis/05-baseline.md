# TASK-01 — фактическая база Red Wings

База собрана из существующих обработанных CSV на фиксированную дату интерпретации
маршрутных свидетельств **10 ноября 2026 года**. Новые источники не загружались,
исходные значения не исправлялись. Изучены условия `case/CASE_BRIEF.md` и README
данных. Результат — подготовка свидетельств для следующего этапа; рейтинг городов,
оценки спроса, H1/H2 и экономика здесь не рассчитываются.

Получено **1 353 записи**: 156 метрик аэропортов, 33 пассажиропотока по направлениям,
638 маршрутных свидетельств и 526 рыночных/контекстных показателей. Это число
записей разных типов, не число независимых наблюдений и не объём перевозок.
Схема и правила описаны в [core/README.md](../data/processed/core/README.md),
реализация и проверки — в [build_core.py](../scripts/build_core.py).

S59 и S60 публикуют показатели группы ЮТэйр и ПАО по разным стандартам и областям:
финансовые и операционные значения сохранены как разные свидетельства с
`reporting_basis`. Они не приводятся к одному «правильному» числу. Аналогично общий
пассажиропоток РФ из S03 — показатель авиакомпаний, а аэропортовый поток из той же
инфографики имеет другую базу учёта. Различия не устраняются арифметикой.

README верхнего уровня `data/processed/README.md` всё ещё говорит «Сейчас пусто»;
это устаревшая документация, не описание фактического состояния файлов.
Статусы `not_downloaded` в реестре и запись в локальном `sources.csv` также описывают
разные вещи. Наличие извлечения не является независимой проверкой сайта издателя.

## Проверки и воспроизводимость

Выполнен `uv run python scripts/build_core.py` на Python 3.14. Проверены ширина
строк всех читаемых входов и четырёх выходов, числовые значения, происхождение,
баланс использованных/исключённых/неприменимых строк. Для каждой выходной записи
сверены с входом source_id, локатор, значение, квалификатор, период, record_kind,
comparison_period, reporting_basis и сохранность limitations, когда эти поля есть.

Предметные проверки подтверждают: ровно 475 S19 и 65 S20; периоды без года не
развёрнуты; для первых двух вариантов Абакана получены 1 и 2 дня полной недели;
Омск → Москва не разделён на аэропорты; все 33 потока имеют unspecified;
анонсы и планы не названы фактическим выполнением; airline_rank — rank;

пассажиров Red Wings 2025 сохранены. Повторная сборка дала идентичные байты
четырёх CSV. Проверки не требуют raw, сети или дополнительных зависимостей.
