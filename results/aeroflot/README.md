# Расчёты по Аэрофлоту S72

Справочные показатели для проверки сезонности и обоснования поэтапной H2.
[Выводы и ограничения](../../analysis/13-aeroflot-benchmark.md).

| CSV | Содержание |
|---|---|
| period_metrics.csv | 324 агрегата: 2019, 2022–2024 целиком; январь–февраль 2024/2025. Суммы пассажиров, груза, почты, рейсов, RPK/ASK; взвешенная загрузка и средняя дальность |
| seasonality.csv | 1 008 строк: месячные значения 2023/2024, дни, среднесуточный поток, доля года и индекс к среднему за день года |
| comparisons.csv | 108 сопоставлений: 2024 к 2023; январь–февраль 2025 к тем же месяцам 2024; исходные величины, абсолютные и относительные изменения |
| source_checks.csv | 252 сверки месячных сумм с опубликованными накопленными значениями; исходные значения сохранены |

Ключ агрегатов: `entity, period, scope, metric`. Единицы сохранены в каждой строке;
пассажиры — тыс. человек, груз и почта — тонны, RPK/ASK — млн соответствующих км.
В `comparisons.csv` поле `unit` относится к изменению: проценты или п.п.;
единицы `before`, `after`, `absolute_change` определяются показателем в `period_metrics.csv`.
Пропуск не заменяется нулём. Группа и авиакомпания не складываются.

Агрегаты и сезонность содержат `source_id`, исходный CSV, физические строки этого CSV,
путь XLS и локаторы его ячеек. Сопоставления ссылаются на ключи агрегатов;
проверки содержат также локатор и CSV-строку опубликованного YTD.

```sh
uv run --frozen --no-sync python scripts/analyze_aeroflot_traffic.py
uv run --frozen --no-sync python scripts/check_aeroflot_analysis.py
```

Первая команда пересоздаёт четыре CSV, аналитический документ и график сезонности.
Вторая проверяет результаты независимо по исходным месячным CSV, не перезаписывая их.
Модель H1/H2 не запускается. Числа и выводы анализа генерируются кодом.
