- [Короткие выводы](notes/FINDINGS.md).

Исходные отчёты Work **не являются первичными файлами издания**. Каталог `data/catalog/` импортирован из текста; часть официальных оригиналов не получена. Проверенные публично доступные сведения хранятся в `data/processed/` со ссылками на страницы издателей. Для загрузки оригиналов предусмотрен `scripts/fetch_sources.py`.

Предыдущие хеш-аудиты, метрики «проверенности» старого сценария и каталог `Проверка/` удалены: они не доказывали реальный спрос или прибыльность.
