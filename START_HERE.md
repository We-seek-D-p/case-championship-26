## Среда Fedora / JetBrains Air

```bash
uv python install 3.14
uv sync
uv run python scripts/import_dr01.py
uv run python scripts/fetch_sources.py --list
uv run python scripts/fetch_sources.py --ids S21 S48 S49 S50 S51
```

Пока нет `uv.lock`: он должен появиться при первом `uv sync` на поддерживаемой среде и попасть в коммит. Затем использовать `uv sync --locked`.

**Не запускайте старые инструкции `Проверка/model.py --verify` и `Проверка/network.py`**: каталог удалён по решению команды, потому что проверки файлов и условных сценариев не доказывают спрос или прибыль. Полезные старые таблицы координат и маршрутов лежат в `data/reference/`; они тоже не доказательство спроса. Старые PDF паспорта/презентации не обновлены после исследований.
