## Запуск на Fedora с uv

```bash
uv python install 3.14
uv sync
uv run python scripts/check_catalog.py
uv run python scripts/import_dr01.py
uv run python scripts/check_catalog.py
```

На этапе начальной подготовки **uv.lock ещё не создан**: здесь не была доступна среда Python 3.14 для реального разрешения и проверки зависимостей. После `uv sync` обязательно добавить сформированный `uv.lock` в Git. В дальнейшем использовать `uv sync --locked` и `uv run --locked ...`.

В старом каталоге `Проверка/` остались прежние независимые расчёты; не включать их результаты в фактическую основу без аудита. Не создавать отдельную виртуальную среду внутри каждой поддиректории — один `pyproject.toml` и один `uv.lock` в корне.
