# Дальнейшая работа по кейсу Red Wings

По исходному заданию 10 ноября 2026 к 23:59: паспорт 1–2 страницы, рейтинг 10+ городов и топ-3, два сценарных расчёта H1/H2, 8–12 маршрутов с источниками спроса и частоты, описание использования ИИ. Защита — 13 ноября: презентация 5–8 слайдов, обновлённый паспорт и дорожная карта.

## Приоритеты

1. [x] Сохранить целиком DR-01/DR-02 и извлечь из DR-01 71 источник / 109 наблюдений в CSV.
2. [x] Повторно прочитать часть официальных публикаций и отдельно выгрузить 15 строк пассажиропотока направлений аэропортов, 8 агрегатов.
3. [x] Убрать устаревшие псевдоаудиты и старую `Проверка/` из текущей ветки.
4. [ ] Скачать доступные оригиналы PDF/HTML командой `uv run python scripts/fetch_sources.py` (в этой среде загрузка напрямую блокируется); зафиксировать реальные ошибки доступа.
5. [ ] Проверить наиболее ценные факты из каталога, особенно O&D, доступность самолётов, тарифы аэропортов, субсидии и расходы на базу.
6. [ ] Из 20 кандидатов построить защищаемый рейтинг не менее 10; выбрать топ-3 по спросу, конкуренции и ресурсам, с неопределённостью.
7. [ ] Разработать минимальный вычислительный конвейер H0/H1/H2; не использовать спрос как `предлагаемые кресла × желаемая загрузка`.
8. [ ] Проверить 8–12 пар и частоты, календарь ВС, базовый/осторожный сценарий, рынок 2028, денежный вклад и порог смены решения.
9. [ ] Обновить паспорт, карту, презентацию и доказательную таблицу `маршрут | пассажиров/год | рейсов/неделю | источник/метод`.

Критическая граница: импорт отчёта — не первичное измерение; опубликованный поток по участку — не O&D-спрос; доступная предложенная вместимость — не продажи; сайт с ценой «от» — не реализованный yield. При отсутствии необходимых данных допустимы только явно обозначенные сценарии и пороги без ложной точности.
