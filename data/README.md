# Данные

- [catalog/](catalog/README.md) — инвентарь источников и наблюдений, с отдельным статусом перепроверки.
- [raw/](raw/README.md) — неизменённые оригинальные документы, реальные выгрузки и снимки; хеш SHA-256, дата получения, URL и редакция обязательны.
- [processed/](processed/README.md) — нормализованные таблицы, создаваемые из raw/ с сохранением обратной связи с источниками.

Пустое поле — **не ноль**. Рекламная цена «от» — **не доход с проданного билета**. Аэропортовый поток — **не O&D спрос**. Предложенное число кресел — **не перевезённые пассажиры**. План поставки — **не свободный борт**.
