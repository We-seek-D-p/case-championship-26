# Локальные исходные данные

Сохраняем скачанные PDF, HTML, XLSX, TXT и другие оригиналы **только на рабочем компьютере**. Исходные страницы могут содержать служебные данные сессии, поэтому все документы внутри `data/raw/` (кроме этого README и файлов `.gitkeep`) игнорируются Git.

В `data/processed/` коммитим **только очищенные структурированные таблицы**, проверенные на отсутствие секретов, cookie, токенов и персональных данных браузерной сессии. Исходные файлы нельзя автоматически переносить в CSV целиком: извлекаем только нужные данные.

| Локальная папка | Тип данных |
|---|---|
| `market/` | Статистика Росавиации и Минтранса |
| `airlines/` | Авиакомпании, маршруты и конкуренты |
| `fleet/` | Парк и ввод самолётов |
| `schedules/` | Опубликованные расписания |
| `airports/` | Статистика аэропортов |
| `demography/` | Росстат и демография |
| `regulation/` | Нормативные материалы |
| `costs/` | Сборы и тарифы аэропортов |

Список публикаций и рекомендуемые имена файлов — [SOURCE_MANIFEST.md](../SOURCE_MANIFEST.md). Локальные файлы могут отличаться по формату; связь с источниками фиксируется в `data/processed/` через `source_id` и локатор.

**Важно при переходе на этот коммит:** ранее семь TXT аэропортов уже были отслеживаемыми. Их удаление из Git может удалить локальные копии при `git pull`. До обновления ветки скопируйте `data/raw/` в отдельную папку вне репозитория и верните после обновления.

Факт удаления из текущего дерева **не удаляет файлы из старой истории Git**. Если там когда-либо оказались секреты, потребуется отдельная процедура очистки истории и замены секретов.
