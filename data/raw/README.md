# Первичные файлы

Здесь будут лежать реально полученные PDF/XLSX/CSV/HTML-снимки. Не смешивать их с отчётами Work и не переписывать содержимое исходников. Для каждого файла зарегистрировать URL страницы, прямой URL файла, дату доступа, версию, SHA-256 и использованные строки/страницы. Если публикация не скачана, не создавать фиктивный raw-файл.
