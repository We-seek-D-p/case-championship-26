# Оригиналы публикаций

Исследовательские отчёты и извлечённые из них значения находятся **не здесь**, а в `research/reports/` и `data/catalog/`.

Для скачивания опубликованных оригиналов из каталога DR-01:

```bash
uv run python scripts/fetch_sources.py --list
uv run python scripts/fetch_sources.py
# либо все доступные адреса; некоторые сайты блокируют автоматические запросы
uv run python scripts/fetch_sources.py --all
# конкретные записи
uv run python scripts/fetch_sources.py --ids S21 S48 S49 S50 S51
```

Скачанные файлы появятся в `data/raw/downloaded/`, журнал — в `download_manifest.csv`. Он содержит ID, страницу публикации, прямой URL, локальный путь и результат запроса. **Хеши и самоподтверждающие «аудиты» не используются**. HTTP 403, CAPTCHA, неподходящий формат и другие ошибки должны остаться ошибками, а не фиктивными данными.

Оригинальные файлы могут быть большими; не добавляйте всё подряд в Git. В репозитории прежде всего нужны обработанные табличные данные с открытыми ссылками и точными локаторами. Скачивание файла само по себе не делает опубликованные цифры достоверными.
