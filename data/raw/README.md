# Первичные файлы от издателей

Смотрите [таблицы источников](../SOURCE_MANIFEST.md) и точные пути в [CSV-реестре](../source_manifest.csv). Каждому источнику соответствует указанное имя файла. **Файлов ещё нет**; пустые папки представлены `.gitkeep`.

| Папка | Тип |
|---|---|
| `market/` | Российский рынок, Росавиация, Минтранс |
| `airlines/` | Релизы перевозчиков, конкуренты и финансовые данные |
| `fleet/` | Парк и ввод самолётов |
| `schedules/` | Расписания авиарейсов |
| `airports/` | Пассажиропотоки аэропортов |
| `demography/` | Демографические документы Росстата |
| `regulation/` | Субсидии, нормативные акты |
| `costs/` | Аэропортовые прейскуранты и смежные расходы |

Сохранять первичные байты без редактирования; не синтезировать отсутствующие таблицы. Данные можно коммитить в Git: `raw/` **не игнорируется**. Для больших или неразрешённых к распространению файлов обсудить Git LFS/внешнее хранение отдельно.
