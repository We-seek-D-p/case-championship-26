# Cargo research — коммерческие грузы на пассажирских рейсах

Изучается возможность дополнительной выручки от перевозки коммерческих грузов и почты в багажно-грузовых отсеках (БГО) пассажирских самолётов. Это **самостоятельная гипотеза**, а не подтверждённый компонент выбранной маршрутной стратегии.

## Состав

| Файл | Назначение |
| --- | --- |
| `documentation/RESEARCH.md` | Полный обзор рынка, типов грузов, практик перевозчиков, ограничений, операционной модели и рисков |
| `documentation/METHODOLOGY.md` | Формулы, классификация источников и правила трактовки |
| `documentation/DATA_GAPS.md` | Что обязательно проверить до включения грузов в финансовую модель Red Wings |
| `documentation/VALIDATION_REPORT.md` | Результаты формальных проверок пакета |
| `processed/market_benchmarks.csv` | Публичные агрегированные значения объёмов авиагрузов |
| `processed/industry_examples.csv` | Проверяемые примеры продуктов и операторов |
| `estimates/assumptions.csv` | Все параметры гипотетического сценария |
| `estimates/scenarios.csv` | Три расчёта чувствительности для S1 (MRV) |
| `sources/sources.csv` | Ссылки, область применимости, период и происхождение |
