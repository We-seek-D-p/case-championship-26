# Исследовательский каталог DR-01

- `sources_dr01.csv` — 71 источник, извлечённый из раздела B отчёта Work.
- `observations_dr01.csv` — 109 строк из раздела C.
- `review_status=report_extracted_not_independently_verified` — прямую публикацию для этих строк наша команда ещё не перепроверяла.

Повторное извлечение таблиц из отчёта:

```bash
uv run python scripts/import_dr01.py
```

Для загрузки оригиналов используйте `scripts/fetch_sources.py`. Отдельного «аудита» с хешами, самопроверками и итоговыми процентами якобы подтверждённых входов больше нет. Независимо прочитанные опубликованные строки хранятся отдельно в `data/processed/`, не меняя статусы импортированного каталога.
