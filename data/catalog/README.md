# Реестр DR-01

- `sources_dr01.csv` — **71** запись каталога источников, извлечённая из раздела B DR-01.
- `observations_dr01.csv` — **109** наблюдений из раздела C DR-01.

Файлы создаются командой:

```bash
uv run python scripts/import_dr01.py
uv run python scripts/check_catalog.py
```

Поле `Статус` сохраняет утверждение автора DR-01. Дополнительное `review_status=report_extracted_not_independently_verified` **не позволяет считать запись перепроверенной командой**. Для перехода к `verified` нужна загрузка оригинального документа, сохранение контрольной суммы, проверка конкретного значения/единицы/периода и локатора.

Не объединять `source_id` DR-01 с одноимёнными идентификаторами старого проекта без явной таблицы соответствия. Цифры `O109` — вычисление, а не первичное наблюдение.
