# Извлечённые сведения из официальных публикаций

- `airport_route_passengers_2025.csv` — 15 строк опубликованного пассажиропотока **по направлениям аэропортов** (Омск: 10; Самара: 5).
- `verified_publication_metrics_2025.csv` — 8 фактических опубликованных агрегатов Red Wings и Минтранса за 2025 год.

Эти строки повторно сопоставлены с доступными официальными страницами и страницей 4 PDF Минтранса 10.11.2026. **Утверждается только соответствие опубликованным значениям**, а не независимое подтверждение числа проданных авиабилетов.

Число направлений не раскрывает O&D-поток; направление суммирования (оба направления вместе или одно) в текстах аэропортов не определено. У округлённых значений сохранён статус `rounded_*`/ `approximately` — их нельзя изображать точными по единицам. Число пассажиров Red Wings относится ко всем маршрутам; доля внутренних перевозок отдельно не раскрыта.

Другие наблюдения из DR-01 остаются в `data/catalog/observations_dr01.csv` со статусом `report_extracted_not_independently_verified`.
