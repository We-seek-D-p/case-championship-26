# Данные для расчёта

| Каталог | Содержание |
|---|---|
| [airports/](airports/README.md) | Пассажиропоток и показатели аэропортов |
| [airlines/](airlines/README.md) | Перевозчики, маршруты, флот и тарифные предложения; четыре CSV статистики Аэрофлота S72 за 2014-01–2025-02 |
| [market/](market/) | Статистика авиаперевозок и отраслевые показатели |
| [flights/](flights/README.md) | Расписание и агрегаты внутренних рейсов |
| [schedules/](schedules/) | Расписания Кольцово и Гагарина |
| [core/](core/README.md) | Четыре таблицы, которые использует модель |

Данные подготовлены и проверены. Источники связаны по `source_id` с
[каталогом публикаций](../SOURCE_MANIFEST.md). Пропуск означает неизвестное значение.
Пассажиропоток аэропорта, поток линии и конечный спрос между городами — разные показатели.

[Выгрузка Аэрофлота S72](airlines/README.md#статистика-аэрофлота-s72) содержит
месячные, накопленные и YoY-показатели группы и отдельной авиакомпании.
В каждом из четырёх CSV 9 916 записей, включая пропуски.
Показатели группы и авиакомпании, а также месячные и накопленные значения не складываются.
S72 — справочная база для анализа; четыре входные таблицы `core/` и модель H1/H2 не менялись.
