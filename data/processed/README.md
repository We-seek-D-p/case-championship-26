# Данные для расчёта

| Каталог | Содержание |
|---|---|
| [airports/](airports/README.md) | Пассажиропоток и показатели аэропортов |
| [airlines/](airlines/README.md) | Перевозчики, маршруты, флот и тарифные предложения |
| [market/](market/) | Статистика авиаперевозок и отраслевые показатели |
| [flights/](flights/README.md) | Расписание и агрегаты внутренних рейсов |
| [schedules/](schedules/) | Расписания Кольцово и Гагарина |
| [core/](core/README.md) | Четыре таблицы, которые использует модель |

Данные подготовлены и проверены. Источники связаны по `source_id` с
[каталогом публикаций](../SOURCE_MANIFEST.md). Пропуск означает неизвестное значение.
Пассажиропоток аэропорта, поток линии и конечный спрос между городами — разные показатели.
