# Извлечения чисел из DR-01

- `airport_route_passengers_2025.csv`: 15 опубликованных в официальных релизах направлений (Омск: 10; Самара: 5).
- `publication_metrics_2025_from_dr01.csv`: 8 опубликованных агрегатов Росавиации и Red Wings за 2025 год, с точными `Sxx/Oxxx` ссылками на каталог отчёта.

**Статус: извлечено из DR-01, но оригинальные официальные документы на этом этапе не скачаны заново и не подтверждены независимо.** Сохранены исходные ссылки, период, способ округления, ограничения использования и ID источников. Для повторной сверки оригиналов используйте `scripts/fetch_sources.py`.

Направления аэропортов — это **не конечный O&D-спрос**. Официальная национальная статистика по перевезённым пассажирам — не пассажиропоток аэропортов. Фраза «2 млн на российских самолётах» — не «2 млн на внутренних рейсах». Числа `reported_value` — опубликованные значения в выбранных единицах, не новая независимая оценка рынка.
