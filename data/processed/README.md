# Нормализованные данные — будущая работа Codex

Сейчас **пусто**. Каждый полученный PDF/HTML/CSV из `data/raw/` обрабатывать полным набором релевантных строк, а не несколькими удобными примерами.

| Поле в результате | Зачем |
|---|---|
| `source_id` | ID из `data/source_manifest.csv` |
| `raw_path` | Исходный скачанный файл |
| `source_locator` | Страница, лист, таблица, номер и строка |
| `metric`, `value`, `unit` | Что измерено и в каких единицах |
| `period` | Период измерения |
| `record_kind` | Наблюдение / расчёт / сценарное предположение |

Не смешивать аэропортовый пассажиропоток с конечным O&D-спросом, расписание с выполненными рейсами, витринную цену с фактическим доходом.
