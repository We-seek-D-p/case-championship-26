# Входные таблицы модели

| Файл | Содержание |
|---|---|
| airports.csv | Метрики аэропортов |
| route_passengers.csv | Пассажиропоток по линиям |
| current_routes.csv | Маршруты, перевозчики и частоты |
| market.csv | Показатели рынка и авиакомпаний |

Источники: [SOURCE_MANIFEST.md](../../SOURCE_MANIFEST.md).
`source_id`, `source_file`, `source_row` и `source_locator` связывают показатель
с публикацией и записью данных. `period` и `unit` задают период и единицу;
`record_kind` различает наблюдения, планы и прогнозы.

Частота расписания относится к указанному периоду; варианты разных периодов
не суммируются. Потоки авиакомпаний используются для доли рынка, аэропортовые
потоки — для рейтинга городов, потоки линий — как аналоги сценарного спроса.
