# Извлечения по аэропортам

Локальные текстовые копии всех 17 источников из `data/raw/airports/`. Файлы издателей HTML/PDF не представлены: извлечение проверено по доступным TXT, без проверки сайтов. Реестр исходников не изменяется; его `not_downloaded` и ожидаемые расширения не описывают фактическое наличие TXT.

| Файл | Гранулярность |
|---|---|
| `metrics.csv` | Один опубликованный показатель × источник × период × область × период сравнения |
| `relations.csv` | Один упомянутый город, перевозчик или тип ВС × вид связи × источник × период |
| `attributes.csv` | Одна характеристика Омского аэропорта из S52 |
| `sources.csv` | Один фактический файл: путь, SHA-256, ссылка и издатель из реестра, покрытие |

Общие поля: `source_id`, фактический `raw_path`, `source_locator` (строки TXT, нумерация с 1, обе границы включены), `airport`. В `sources.csv` поле `source_status` перенесено из реестра и не является результатом независимой проверки. `capture_date` пусто: дата получения неизвестна.

`period`: год, месяц или диапазон месяцев `YYYY-MM/YYYY-MM`. `2026-summer` означает три летних месяца из S33; точные календарные границы в тексте не названы. `2026/2028` — многолетний период плана. Пустой период означает, что источник его не устанавливает. Исторические значения из S25 сохранены за каждый явно указанный год. Сравнения относятся к `comparison_period`, а не дате публикации.

`metric` задаёт показатель; `scope` — `total`, `domestic`, `international`, `route:город`, `airline:перевозчик` или иной явно обозначенный сегмент. Наименования городов и авиакомпаний сохранены без подстановки кодов из внешних справочников. Направление может объединять аэропорты города. Имена аэропортов установлены по тексту и реестру; S32 в самом тексте аэропорт не называет.

`value` — десятичное число с точкой; масштаб «тыс.»/«млн» раскрыт в единицах `unit`. `percent` — процент в масштабе 0–100 (например, рост на 4% хранится как 4, а не 0.04); показатель изменения — относительное изменение в процентах, не разница долей в процентных пунктах. `ratio` — кратность (не процент). `tonne` и `kg`, груз, почта, груз с почтой и багаж остаются разными единицами и показателями. Самолётовылеты, рейсы, взлётно-посадочные операции и обслуженные ВС не объединяются.

`value_qualifier`: `reported` — значение в указанной источником точности, **не гарантия точного подсчёта**; `approximately` — около/порядка; `almost` — почти; `greater_than` — более/превысил; `at_least` — не менее; `at_most` — до. Нижние и верхние границы нельзя использовать как точечные оценки без явного допущения. `record_kind=observation` означает опубликованное наблюдение, `plan` — план/цель; `reported_relation` и `reported_attribute` — качественные сведения из текста. Ни одна строка не является модельной оценкой.

В `attributes.csv` сложные характеристики (перечень ВС с условиями, координаты, PCN) сохранены дословно, без неоднозначного разбиения. У размера ВПП `2500 х 45` и максимального взлётного веса `191` в доступном тексте нет единиц: `unit` пусто. Период S52 не указан; не считать эти характеристики подтверждением текущего допуска конкретного рейса.

Пассажиропоток аэропортов не равен числу уникальных пассажиров и конечному O&D-спросу. Список популярных/новых направлений не является полным расписанием. `relations.csv` не задаёт частоты или сроки действия рейсов. Список регулярных перевозчиков S34 и перечисленные направления извлечены полностью; финансовые показатели S26 и планы S41 отделены типом показателя и `record_kind`.

Повторная сборка и проверка из корня проекта (Python, стандартная библиотека):

```sh
python scripts/process_airports.py
python scripts/check_airports.py
```

Спецификации извлечения в скрипте проверены по строкам доступных текстов. Хеши позволяют выявить смену источника; при изменении текста нужно заново проверить смысл показателей и локаторы. Проверки не подменяют независимый аудит публикаций.
