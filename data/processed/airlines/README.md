### Структура записей

Уникальный ключ внутри каждого CSV: `entity, period, metric, scope`.
`entity` сохраняет `Aeroflot Group` или `Aeroflot Airline`;
`reporting_basis` — соответственно `group` или `airline`.
`scope` принимает `total`, `international`, `domestic`; у налёта часов есть только `total`.

| Поля | Смысл |
|---|---|
| `source_id`, `raw_path` | ID источника и путь от корня проекта |
| `source_sheet`, `source_row`, `source_column`, `source_locator` | Лист, строка Excel с 1, буквенный столбец и точная ячейка |
| `source_metric`, `source_unit`, `source_period`, `source_format`, `source_cell_type` | Исходные подписи, формат Excel и тип xlrd: 1 — текст, 2 — число, 0/6 — пустая ячейка |
| `period`, `period_start`, `period_end` | Отчётный месяц `YYYY-MM` и включительные границы периода; YTD начинается 1 января |
| `comparison_period` | Для YoY: месяц прошлого года либо диапазон `YYYY-01/YYYY-MM`; у абсолютных значений пусто |
| `metric`, `scope`, `value`, `unit` | Нормализованные показатель, охват, число и единица |
| `raw_value` | Исходный текст или строковое представление числа Excel без округления при выгрузке |
| `value_qualifier` | `reported`, `reported_multiple`, `missing_blank`, `missing_dash` |
| `record_kind`, `limitations` | `observation` и ограничения конкретной записи, включая расхождения |

`source_unit` сохраняется буквально, в том числе знак повтора `-"-`.
Нормализованная единица находится в `unit`. Числа Excel выгружаются по сохранённым
значениям ячеек; пересчёт формул не выполняется. `source_format` сохраняет формат
отображения, а `raw_value` — хранимое значение, которое может быть точнее видимого.

### Нормализация и ограничения

- Числовые доли Excel переводятся в проценты умножением на 100. Текст `93,9%`
  становится `93.9 percent`. Изменение YoY — прирост, а не индекс к прошлому году.
- Изменение загрузки сохраняется в `percentage_point`. В накопленном YoY-блоке
  заголовок ошибочно указывает `%`; значения имеют масштаб п.п., как в месячном блоке.
- Текст `11,2х` становится `11.2 times`, с `reported_multiple`. Это опубликованная
  кратность; она не преобразуется в процентный прирост.
- Пустая ячейка и `-` сохраняются как разные квалификаторы; `value` остаётся пустым.
  Рейсы в абсолютных блоках начинаются с января 2016 года. На листе группы также
  отсутствуют шесть месячных YoY-изменений загрузки за январь 2015 года.
- На листе `Aeroflot Airline` ячейка `DB45` подписана `June 2021` вместо июня 2022.
  Период нормализован в `2022-06`: его подтверждают `DB2`, `DB88`, `DB131` и соседние
  месяцы. Все 37 записей этого столбца содержат исходный заголовок в `source_period`
  и объяснение исправления в `limitations`. Числовые значения не изменены.
- У группы есть 28 пар различающихся январских Monthly/YTD YoY-значений:
  15 за январь 2023 и 13 за январь 2025. Обе стороны каждой пары отмечены в
  `limitations`, с локаторами и исходными значениями. Например, налёт за январь 2025:
  `EG72` — +4.781187317713287%, `EG158` — −4.933709712059475%.
  Причина расхождений не установлена; исправления не вносились.
- Группа включает авиакомпанию; `total` включает международные и внутренние
  перевозки; `cargo_and_mail` включает груз и почту. Эти уровни нельзя складывать.
  Накопленные периоды нельзя суммировать с месячными. Загрузку за период нельзя
  получать простым средним месячных процентов.

### Воспроизведение и проверка

Из корня проекта, Python 3.14. `xlrd` подключается временно, без изменения
зависимостей проекта:

```sh
uv run --frozen --no-sync --with xlrd==2.0.2 python scripts/parse_aeroflot_traffic.py
uv run --frozen --no-sync --with xlrd==2.0.2 python scripts/parse_aeroflot_traffic.py --check
```

Первая команда создаёт четыре CSV и проверяет записанный результат. Вторая
читает существующие CSV без перезаписи. Проверки охватывают 39 664 ячейки:
полноту прямоугольников источника, уникальность ключей и локаторов, периоды,
исходные значения и типы, масштаб нормализации, границы абсолютной загрузки,
различение пропусков и точное совпадение сохранённых CSV с разбором XLS.
Расхождения январских Monthly/YTD-значений отмечаются, а не считаются ошибкой парсера.
Проверка не подтверждает достоверность опубликованной статистики и не является
полной сверкой всех экономических тождеств источника.
