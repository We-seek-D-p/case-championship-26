# Авиакомпании

| Файл | Содержание |
|---|---|
| metrics.csv | Пассажиры, флот, финансы и показатели сети |
| routes.csv | Направления и опубликованные программы рейсов |
| relations.csv | Аэропорты, базы и другие связи |
| fares.csv | Тарифные предложения |
| tariff_rules.csv | Условия тарифов |
| attributes.csv | Характеристики самолётов |
| sources.csv | Источники |

[Каталог публикаций](../../SOURCE_MANIFEST.md#s08).
Цены «от» — предложения продажи; в модели реализованный тариф задаётся отдельно.
Показатели группы и отдельной авиакомпании сохраняются раздельно.
