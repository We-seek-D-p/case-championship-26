# Извлечения по авиакомпаниям

Обработаны все 16 доступных источников в `data/raw/airlines/`: 15 HTML и PDF-журнал S61 (65 физических страниц). Исходники не изменяются. CSV — UTF-8 с заголовками; пустое поле означает отсутствие значения или неприменимость, не ноль.

| Файл | Гранулярность | Строк |
|---|---|---:|
| `metrics.csv` | Показатель × субъект × источник × период × область × стандарт/контекст отчётности | 130 |
| `relations.csv` | Одна качественная связь: хаб, страна, направление без установленного отправления, партнёр, узел карты | 169 |
| `routes.csv` | Объявленное/упомянутое направление либо вариант опубликованного графика | 98 |
| `fares.csv` | Одно ценовое предложение для перечисленных рейсов/направлений | 107 |
| `tariff_rules.csv` | Одно условие тарифа или дополнительной услуги | 77 |
| `attributes.csv` | Сложная характеристика SSJ100 | 2 |
| `sources.csv` | Один фактический исходник, SHA-256, метаданные и счётчики извлечения | 16 |

## Происхождение

Все предметные записи содержат `source_id`, `raw_path`, `source_locator`, `source_excerpt`. Локатор HTML задаёт класс контейнера, его порядковое вхождение (с 1), затем полуоткрытый диапазон символов нормализованного текста (с 0). Текст извлекается стандартным HTMLParser: текстовые узлы объединяются пробелами, последовательности пробелов сворачиваются, script/style исключаются. Для новостей Red Wings используется второй контейнер `post`, а не соседние блоки заголовка/подвала. Для S22 используется весь сохранённый `directions__list`, включая имеющиеся в DOM карточки независимо от текущего фильтра интерфейса.

Локатор PDF задаёт **физическую страницу файла с 1**, не печатный номер журнала, и такой же диапазон нормализованного текста из `pdftotext -layout`. Например, физические страницы 7–8 соответствуют печатным 12–13; 59–60 — 74–75; 64–65 — 79–80. `reviewed_offer` дополнительно нумерует ценовые записи PDF в порядке спецификации извлечения. Одинаковая цена может встречаться на странице несколько раз: диапазон указывает найденную сумму, а маршрут/номер рейса сверены вручную с изображением страницы. Проверять эти строки следует вместе с соответствующей страницей, не только числовым фрагментом.

В `sources.csv` `published_date` — дата публикации из страницы, `issue_period` — месяц номера журнала, `capture_date` пусто: дата получения неизвестна. URL и издатель перенесены из `data/source_manifest.csv`; `claimed_status` — метка реестра, а не новый независимый аудит. S58 и S69 — перепечатки пресс-релизов. Недоступные файлы S57, S62, S63 из общего реестра не создавались и не считались обработанными.

## Типы и ограничения

- `period` передаёт точность источника: год, месяц, диапазон месяцев, сезон с указанным окончанием, `as_of_дата` (на дату публикации), `issue_2026-01` (контекст номера журнала). `first_project_year` и `first_5_hub_years` оставлены как периоды работы проекта; календарные границы не домыслены. Даты публикации не подставляются вместо периода наблюдения.
- `entity` разделяет авиакомпанию, группу, техническое подразделение и аэропорт. `scope` выделяет самолётный/вертолётный сегмент, хаб, парк, внутренние и международные перевозки. Итоги аэропорта Кольцово из S17 и аэропорта Сургут из S59 не являются перевозками авиакомпании.
- `reporting_basis=IFRS` — финансовые показатели группы из S59; `IFRS_release` — операционные сведения той же публикации; `RAS` — сведения ПАО из S60. Различающиеся показатели не согласовываются принудительно. Пустая база означает, что для данного показателя стандарт не задан.
- Числа хранятся с десятичной точкой, «тыс.»/«млн»/«млрд» раскрываются в единицы `unit`. `percent` означает процент в масштабе 0–100, `percentage_point` — изменение в процентных пунктах. `percent_as_reported` оставляет неуточнённый вид изменения загрузки из S08. Не конвертировать его автоматически в процентные пункты.
- `value_qualifier`: `reported` — опубликованное значение в точности источника, без гарантии точного подсчёта; `greater_than` — более; `almost` — почти; `approximately` — около; `at_most` — до/не более; `at_least` — от/не менее. Нижние границы цен не являются средними ценами.
- `record_kind` различает наблюдения, планы, прогнозы, программу расписания, объявленное сообщение, опубликованный график, рекламные цены и правила. Запуск рейса в новости не подтверждает выполнение всего будущего расписания.
- `routes.csv`: понедельник=1, воскресенье=7; ежедневно в S17 пересчитано в 7 рейсов/неделю с пометкой. Частоты направлений из Екатеринбурга относятся к заявлению о программе; точный интервал действия обычно неизвестен. Вылет и прилёт даны только там, где их публикует источник. Для графика S61 часовая основа не указана. Даты без года дополнены годом публикации только при однозначном контексте, что отражено в ограничениях. Обратные направления автоматически не генерируются.
- `relations.csv`: узлы рекламной карты S61 извлечены как узлы, без восстановления рёбер по пересекающимся линиям. Повторная надпись «Магнитогорск» на одной карте не создаёт второй город. Картографические варианты названий городов сохранены. Перечень узлов не является расписанием. Для грузинской программы S11 не строится декартово произведение перечисленных отправлений и назначений.
- `fares.csv`: `direction_scope=both_listed_directions` означает общую опубликованную цену для двух перечисленных направлений, **не билет туда-обратно**. `journey_basis=one_way` устанавливается лишь там, где прямо написано «в одном направлении»; иначе `not_specified`. `additional_fees=charged_extra` означает явно указанные дополнительные сборы; `not_specified` не означает их отсутствие. S22 не сообщает дат поездки, бренда тарифа и актуальности. Цены не являются выручкой, доходностью маршрута или подтверждением доступности мест.
- В S61 у Москва—Кутаиси нет слова «от»: цена сохранена с `reported`. Для А47030 сохранено напечатанное направление Москва—Ереван; необычный номер A46125/6125 также сохранён. Не восстанавливать обратное направление или «правильный» номер по предположению. В номерах источника встречаются визуально одинаковые латинская A и кириллическая А; для сравнения допустима отдельная явная нормализация, исходные записи не исправлялись по справочнику.
- `tariff_rules.csv`: условия разных страниц сохраняются отдельными строками с локаторами, включая различающиеся наборы кодов тарифа «Гибкий». `free` и `not_allowed` — категориальные значения; ноль сбора используется только для явно бесплатного действия. Отсутствующий вес при отсутствии включённого багажа оставлен пустым. Сборы за обмен/возврат имеют примечание о методике с 19.11.2025 и прежних правилах для более ранних билетов. Это извлечение архивных условий, не рекомендация пассажиру о действующих правилах.

## Воспроизведение

Нужны Python и установленный Poppler (`pdftotext`). Python-зависимостей сверх стандартной библиотеки нет.

```sh
python scripts/process_airlines.py
python scripts/check_airlines.py
```

Спецификации извлечения в `scripts/process_airlines.py` проверены по локальным материалам. SHA-256 проверенных исходников закреплены в коде: при изменении файла сборка остановится до повторной проверки спецификаций. Для визуальной сверки PDF применялся `pdftoppm`; временные изображения в результаты не входят. Автоматические проверки охватывают источники, локаторы, ключи, сложные случаи, периоды, правила, структуру CSV и шаблоны чувствительных данных.
