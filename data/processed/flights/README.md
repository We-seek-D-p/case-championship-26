# Рейсы — доступные исходные количественные данные

Здесь собраны два разных типа данных. **Их нельзя объединять в один показатель «реально выполненные рейсы».**

| Файл | Содержание | Источник | Ограничение |
|---|---|---|---|
| `scheduled_departures_winter_2026_27.csv` | **540 строк опубликованного расписания**: 475 Кольцово и 65 Гагарин | [S19](https://ar-svx.ru/schedule/), [S20](https://ar-gsv.ru/schedule/) | Строка — вариант расписания на период, **не выполненный рейс и не пассажир** |
| `russia_domestic_flights_2025.csv` | **2 опубликованных агрегата** о выполненных внутренних рейсах | [S05, Минтранс, физическая с. 5](https://mintrans.gov.ru/file/557797) | Данные по всей России, без разбивки по аэропортам и направлениям; числа округлены |

## Поля расписания

Каждая строка содержит отправной и конечный аэропорты, авиакомпанию, номер рейса, местное время, дни недели, исходный период действия и локатор в обработанной таблице. Это механическое объединение существующих [S19.csv](../schedules/S19.csv) и [S20.csv](../schedules/S20.csv), **без дополнительных рейсов и без моделирования**.

Значения `validity_as_published` сохраняют исходную запись вида `26 окт / 23 ноя`: они не развёрнуты в конкретные даты. Разворачивание по датам требует внимательной проверки года, границ периода и часовых поясов. Все строки — вылеты из соответствующего аэропорта.

## Почему не добавлен внешний CSV с «фактическими рейсами по направлениям»

Сведения об отдельных выполненных рейсах, объёме перевезённых пассажиров по паре и загрузке **не подтверждены этими источниками**. Многогигабайтные исторические ADS-B архивы не заменяют маршрутный спрос России в 2025–2026 годах. Ничего не загружено «для количества строк». Источники с доступной публичной маршрутной статистикой следует анализировать отдельно, не подменяя её расписанием.

## Обращение с сырыми файлами

Локальные HTML/PDF из `data/raw/` **не добавлять в Git**: в них могут содержаться данные браузерной сессии. В репозитории должны оставаться только подготовленные таблицы и ссылки на публичные страницы первоисточников.
