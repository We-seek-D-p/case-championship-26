# Справочные входы из старого расчёта

Сохранены только две предметные таблицы из ранее существовавшего каталога `Проверка/inputs/`:

- `legacy_airport_coordinates.csv` — география аэропортов; источник и точность проверить перед дальнейшим использованием.
- `legacy_route_candidates.csv` — старый список кандидатов и предложения тарифов «от»; **это не пассажирский спрос и не реализованная выручка**.

Это **не подтверждённые рыночные исходные данные**. Старые веса рейтинга, сценарные расходы, демонстрационные расписания, тесты и функции хеш-аудита не перенесены. Сведения остаются доступны в истории Git до коммита очистки, но не входят в новую модель автоматически.
