# Сценарии модели

Здесь появятся TOML-сценарии H0 (исходная сеть), H1 (новый хаб), H2 (прямые рейсы), базовый и осторожный. Пока **нет подтверждённых входов для полной количественной модели**, конфигурации с выдуманными тарифами, загрузкой и затратами намеренно не созданы. Сохранять единый календарь поставок и одинаковые определения метрик для каждой гипотезы.
