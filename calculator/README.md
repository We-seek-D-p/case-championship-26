# Red Wings / Маршрутный калькулятор

Клиентское Nuxt 4 приложение для сценарной демонстрации MRV / NUX. Локальная экономика, карта MapLibre, графики ECharts, ручное распределение флота, OD-лимиты, груз, экспорт CSV/JSON и localStorage. Первый экран S1, SSJ100 100 кресел.

Из корня:

```sh
mise run calculator:install
mise run calculator:dev
```

Открыть адрес Nuxt в терминале (обычно http://127.0.0.1:3000). Последующие запуски — одна команда `mise run calculator:dev`.

```sh
mise run calculator:build
mise exec -- pnpm -C calculator typecheck
mise exec -- pnpm -C calculator lint
mise exec -- pnpm -C calculator generate
mise exec -- pnpm -C calculator preview
```

Node 24, pnpm 12.15.0 из корневого mise; независимый lockfile. JSON подготавливается автоматически, исходные CSV не изменяются. Для обновления отдельно: `mise exec -- pnpm -C calculator data:prepare`.

Сегмент — один перелёт пассажира. Оборот — туда и обратно. База — место размещения программы; хаб — организация пересадок. Экономический режим открытия и переключатель пересадок независимы.

Профиль gg применим к SSJ100. Другие типы требуют собственных расходов, BH, ресурса, владения; пока они неизвестны, прибыль не рассчитана. Доступность самолётов, расписание, слоты, O&D и ёмкость груза не подтверждены. Карта требует сеть для подложки, имеет нейтральную схему при ошибке; при отсутствии WebGL работает таблица.
